# Security policy

Do not disclose vulnerabilities in public issues. Report them privately through [GitHub Security Advisories](https://github.com/Tinkora/mcp_schema_compat/security/advisories/new). Include reproduction steps, affected version, and impact. We do not execute input files or contact remote services during validation.

## 安全策略

请勿在公开 issue 中披露漏洞。请通过 [GitHub Security Advisories](https://github.com/Tinkora/mcp_schema_compat/security/advisories/new) 私下报告，并附复现步骤、受影响版本和影响范围。本工具校验期间不会执行输入文件或访问远程服务。
