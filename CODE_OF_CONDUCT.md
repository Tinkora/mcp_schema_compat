# Code of Conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, assume good faith, and keep discussions focused on improving the project. Report unacceptable behavior privately to the maintainers through GitHub.

## 行为准则

本项目遵循 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。请保持尊重、善意交流，并围绕改进项目展开讨论。不可接受的行为请通过 GitHub 私下联系维护者。
