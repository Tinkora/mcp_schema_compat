# Contributing

Thanks for improving `mcp_schema_compat`. Please open an issue before substantial changes and keep pull requests focused.

## Workflow

1. Fork or create a short-lived branch from `main`.
2. Add tests for behavior changes and update both README languages when user-facing behavior changes.
3. Run the Rust checks listed in [AGENTS.md](AGENTS.md).
4. Use an English Conventional Commit and describe compatibility or security impact in the pull request.

Maintainers merge only changes with passing required checks and a clear review trail.

## 贡献

感谢改进 `mcp_schema_compat`。重大改动请先创建 issue，Pull Request 应保持单一目标。

请从 `main` 创建短期分支，为行为变化补充测试，同步更新双语 README，运行 [AGENTS.md](AGENTS.md) 中的 Rust 检查，并使用英文 Conventional Commit。维护者只合并必需检查通过且说明清晰的变更。
